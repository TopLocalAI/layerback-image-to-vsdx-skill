# LayerBack Diagram Builder — Privacy Policy

Effective date: September 5, 2026

This policy applies only to the LayerBack Diagram Builder Chrome extension.

## Local processing

The extension processes text that you enter entirely on your device. It does not collect, transmit, sell, or share your draft text, generated documents, or personal information with the developer or third parties. It contains no analytics, advertising, tracking, or remote executable code. It does not read browsing history, other tabs, website contents, or account credentials.

## Local storage and exports

Draft text is stored in the extension's local storage on your device so you can continue later. Use Clear draft to remove it. Removing the extension removes its extension storage. Exports are created locally and saved only when you choose to download them; downloaded files remain wherever you save them. You control any later sharing of these files.

## Optional website links

The optional website link opens a separate service. No draft text is included in that link or automatically uploaded. The website's own privacy policy applies if you choose to use that service. Core extension functionality requires no account, payment, or network connection.

## Changes

If the extension's data practices change, this policy will be updated before the new behavior is released.
